# SeizureDetection
## Setup Instructions

Due to GitHub's file size limits, the raw EEG data is not included in this repository. To run the notebook locally:

1. Clone this repository to your machine.
2. Download the [CHB-MIT subset (chb01_03.edf)](https://physionet.org/content/chbmit/1.0.0/chb01/) from PhysioNet.
3. Place the `chb01_03.edf` file directly in the root folder of this project.
4. Run the Jupyter Notebook.
